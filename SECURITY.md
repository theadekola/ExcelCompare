# Security Policy

## Reporting a vulnerability

Please do not publish sensitive security findings in a public GitHub issue.

Report vulnerabilities privately to AAT-Tech Ltd with:

- affected version;
- reproduction steps;
- expected and actual behaviour;
- sample files with personal or confidential data removed; and
- any suggested mitigation.

Do not include real payroll, employee, customer, financial, school, or audit records in reports.

## Supported versions

Security updates are provided for the latest published release where practical.
