# Contributing

Excel Compare Professional is a proprietary AAT-Tech Ltd project.

Before submitting a pull request:

1. open an issue describing the proposed change;
2. avoid committing build outputs, installers, DLLs, personal files, or confidential spreadsheets;
3. keep changes compatible with C++20, Qt 6, and the existing CMake build;
4. update documentation when behaviour changes; and
5. confirm that sample data contains no personal or confidential information.

By submitting a contribution, you confirm that you have the right to provide it and agree that AAT-Tech Ltd may use it within the project.
