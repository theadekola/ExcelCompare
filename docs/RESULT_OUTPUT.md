# Result output format

Version 1.6 displays comparison results using the selected mapped spreadsheet columns.

The Excel report contains:

- **Summary**: totals and a preview of the first 100 result records.
- **Comparison Results**: one record per row, with separate Workbook 1 and Workbook 2 columns for every mapped field.
- **Detailed Changes**: one row for each modified field.

New Record and deleted records are no longer joined into one cell with pipe (`|`) separators.
