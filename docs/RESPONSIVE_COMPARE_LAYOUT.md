# Responsive Compare Layout

Version 2.0.1 places comparison and merge actions inside the Column Mapping and Actions panel.

- Compare only and Compare and merge are selectable operation buttons.
- Start Comparison appears directly below the operation controls.
- Merge settings and merged preview are shown only in Compare and merge mode.
- The page uses a resizable scroll area and splitter so it remains usable on laptops, standard monitors, and large desktop screens.
- Workbook preview panels and mapping tables expand with the available window size.
