# Excel Compare Professional 1.3 Interface

The application now uses a commercial desktop layout with a permanent dark navigation bar.

## Pages

- Compare Files: load, preview, map, compare and merge spreadsheets.
- Results: summary cards, search, status filtering and colour-coded record differences.
- Reports: report preview plus Excel, PDF and CSV exports.
- Audit Log: records loading, comparison, merge and export activity.
- Settings: default matching and legacy-format guidance.
- About: version and AAT-Tech Ltd product information.

## Workflow

1. Select Workbook 1 and Workbook 2.
2. Select each workbook with Browse. It loads and previews automatically.
3. Select worksheets independently.
4. Review automatic column mapping.
5. Click Select key columns and choose one or more unique identifiers.
6. Start Comparison or select a merge mode and click Merge and Save.
