# Auto-map selection

Auto mapping is optional. After loading both workbooks:

1. Tick **Compare** to mark matching columns for comparison.
2. Tick **Merge** to mark columns for merged output.
3. Tick both to use mapped columns for both operations.
4. Leave both unticked to create mappings without selecting them.
5. Click **Auto-map columns**.

The application does not auto-map when a workbook or worksheet is loaded.
