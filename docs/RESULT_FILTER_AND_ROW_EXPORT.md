# Results filtering and row-format export

Version 1.8 keeps every New Records, Unmatched, Modified and Matched comparison record in the result set. The Results status dropdown can therefore display each category independently or all categories together.

The Excel **Comparison Results** worksheet mirrors the application table: one record per row and one output field per column. It does not create duplicate Workbook 1 / Workbook 2 columns. Modified cells are displayed as `old value -> new value`, and each complete row retains its status colour.
