Excel Compare Professional 1.1 Help

Publisher: AAT-Tech Ltd

Quick start

  1. Select the previous spreadsheet and the updated spreadsheet.
  2. Click Load workbooks.
  3. Select one or more stable key columns, such as Employee ID or Invoice Number.
  4. Choose whether to compare all worksheets.
  5. Click Compare workbooks.
  6. Double-click a result to see field-level details.
  7. Export the results to Excel, PDF or CSV.

Supported files

Native support: .xlsx, .csv, .tsv and .tab.

LibreOffice conversion support: .xls, .xlsb, .xlsm, .xlt, .xltx, .xltm, .ods and .fods.

Your original file is not changed. Converted files are created in a temporary folder and removed automatically.
Legacy formats require LibreOffice. Use the Start Menu shortcut named Install Legacy Format Support, or run tools\install-libreoffice.bat.

Status colours

Green: added. Red: deleted. Amber: modified. Grey: unchanged.

Intelligent matching

Records are matched using selected key columns rather than row number, so sorted or moved records are still matched correctly.

Limitations

Macros are not executed or compared. Password-protected files must be unlocked first. CSV and TSV files are treated as one worksheet.

Compare and merge workflow

  1. Load Workbook 1 and Workbook 2.
  2. Select a worksheet from each workbook and review the side-by-side previews.
  3. Open Column mapping and map corresponding fields.
  4. Tick Key for the record identifier, Compare for audited fields, and Use for merged output fields.
  5. Choose a merge mode and conflict policy.
  6. Run a comparison or create a new merged Excel workbook.

The source workbooks are never overwritten.
