# Merge Preview and Column Selection

Version 1.5 adds a redesigned Compare Files workspace.

- Workbook previews are displayed side by side.
- File selectors appear beneath each preview panel.
- Use the Merge checkbox to choose specific output columns.
- Number of columns to merge limits the checked mappings in mapping order.
- Preview merged output generates an in-app preview of up to 100 rows.
- Save preview as Excel is enabled only after a successful preview.
